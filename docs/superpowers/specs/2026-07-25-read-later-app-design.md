# ReadLater App 设计文档

## 1. 项目概述

一个基于 AI Agent 的 Android 稍后阅读和收藏管理应用。用户粘贴链接后，App 通过大模型 API 自动抓取文章内容、生成摘要、打标签，提供干净的阅读体验和高效的收藏管理。

### 核心定位
- 开源免费的 Cubox 替代品
- AI Agent 驱动的内容处理
- 本地优先，可选云同步

## 2. 设计风格

| 维度 | 决定 |
|------|------|
| UI 框架 | Material You (Material Design 3) |
| 默认种子色 | 琥珀橙 (#FF9800) |
| 动态取色 | 支持，跟随壁纸主题 |
| 深色模式 | 支持，跟随系统或手动切换 |
| 图标库 | Material Symbols |

## 3. 信息架构

### 底部导航（四标签）
1. **收件箱** — 新保存的文章，待阅读
2. **标签** — 按标签分类浏览所有文章
3. **收藏夹** — 用户主动收藏的重要文章
4. **设置** — LLM 配置、同步设置、主题等

### 页面结构
```
App
├── 收件箱页（文章列表）
├── 标签页（标签列表 → 标签下文章列表）
├── 收藏夹页（已收藏文章列表）
├── 设置页
│   ├── LLM Provider 配置
│   ├── 云同步配置（WebDAV）
│   ├── 主题设置
│   └── 数据导入/导出
├── 阅读器页（点击文章进入）
│   ├── 顶部：返回 + 来源网址 + 更多操作
│   ├── AI 摘要卡片
│   ├── 正文内容（可高亮标注）
│   └── 底部：标签 / 笔记 / 收藏 / 分享
└── 添加链接页（粘贴 URL）
    ├── URL 输入框
    ├── AI 自动识别结果预览
    └── 保存按钮
```

## 4. 文章卡片设计

收件箱中的每篇文章采用**缩略图 + 信息**布局：
- 左侧：网站缩略图 / favicon（64x64）
- 右侧：标题 + 来源域名 + 阅读时间 + 标签 chips
- 未读状态有视觉区分（如左侧色条）

## 5. 阅读器设计

采用**经典阅读器**模式：
- 顶部导航栏：返回箭头 + 来源域名 + 更多操作（⋯）
- AI 摘要卡片：浅橙色背景，展示 AI 生成的摘要
- 正文区域：干净排版，支持高亮标注
- 底部操作栏：标签 / 笔记 / 收藏 / 分享

### 标注功能
- 长按选中文字 → 弹出工具栏
- 支持：高亮、添加笔记、复制
- 高亮颜色：默认琥珀色

## 6. 添加链接流程

采用**一键静默保存**模式：
1. 用户粘贴 URL
2. 立即保存到收件箱（显示成功 Toast）
3. 后台调用 AI Agent 处理：
   - 抓取网页正文
   - 生成标题、摘要
   - 自动打标签
4. 处理完成后更新文章卡片信息

## 7. AI Agent 架构

### Agent 工作流
```
用户粘贴 URL
    ↓
App 保存到本地数据库（状态：pending）
    ↓
调用 LLM API（Function Calling）
    ├── fetch_content(url) → 抓取网页正文
    ├── summarize(content) → 生成摘要
    └── auto_tag(content) → 自动标签
    ↓
结果写回数据库（状态：ready）
    ↓
UI 自动刷新
```

### Skill 设计（Tool Calling）

每个 Skill 对应一个 Function：

| Skill | 参数 | 返回值 | 实现方式 |
|-------|------|--------|----------|
| `fetch_content` | `{url: string}` | `{title, content, description, image}` | Jsoup 解析 HTML |
| `summarize` | `{content: string, max_length: number}` | `{summary: string}` | 调 LLM API |
| `auto_tag` | `{content: string, existing_tags: string[]}` | `{tags: string[]}` | 调 LLM API |

### 多 Provider 支持

统一接口设计：
```kotlin
interface LlmProvider {
    val name: String
    val baseUrl: String
    suspend fun chat(
        messages: List<ChatMessage>,
        tools: List<ToolDefinition>?
    ): LlmResponse
}
```

支持的 Provider：
- OpenAI（GPT-4o / GPT-4.1）
- Ollama（本地模型）
- DeepSeek
- 通义千问（Qwen）
- 任何 OpenAI 兼容 API

### Provider 配置数据模型
```kotlin
data class LlmConfig(
    val id: String,
    val provider: String,        // "openai" | "ollama" | "deepseek" | ...
    val baseUrl: String,
    val apiKey: String?,         // Ollama 不需要
    val model: String,
    val isEnabled: Boolean
)
```

## 8. 数据存储

### 本地存储（Room + SQLite）
```kotlin
// 文章
@Entity
data class Article(
    val id: String,
    val url: String,
    val title: String?,
    val content: String?,        // 全文 HTML
    val plainText: String?,      // 纯文本
    val summary: String?,        // AI 摘要
    val imageUrl: String?,
    val sourceDomain: String,
    val readingTimeMinutes: Int?,
    val status: ArticleStatus,   // PENDING | PROCESSING | READY | ERROR
    val isFavorite: Boolean,
    val createdAt: Long,
    val updatedAt: Long
)

// 标签
@Entity
data class Tag(
    val id: String,
    val name: String,
    val color: String?,
    val isAutoGenerated: Boolean
)

// 文章-标签关联
@Entity
data class ArticleTag(
    val articleId: String,
    val tagId: String
)

// 高亮/笔记
@Entity
data class Highlight(
    val id: String,
    val articleId: String,
    val selectedText: String,
    val note: String?,
    val color: String,
    val startOffset: Int,
    val endOffset: Int,
    val createdAt: Long
)
```

### 云同步（可选）
- 协议：WebDAV
- 同步内容：文章、标签、高亮、笔记
- 冲突策略：最后修改时间优先
- 实现库：Sardine for Android
