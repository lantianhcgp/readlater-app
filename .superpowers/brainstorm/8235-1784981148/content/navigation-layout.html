A. 三标签极简

收件箱 → 收藏夹 → 设置。最简单的结构，适合纯稍后阅读场景。

优点

  • 认知负担最低
  • 核心流程一目了然

缺点

  • 标签/分类入口深
  • 扩展性差

B. 四标签均衡（推荐）

  • 功能分区清晰
  • 扩展性好

缺点

  • 稍多一个 Tab

C. FAB 快速添加

底部 Tab + 悬浮按钮快速添加链接。搜索独立为 Tab。

优点

  • 添加链接最快
  • 搜索入口明显

缺点

  • 标签管理没有独立入口
  • FAB 可能遮挡内容
